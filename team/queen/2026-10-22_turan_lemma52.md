# [DRAFT — PARKED 2026-10-22] (i) Quantitative Lemma 5.2: separating the target zero (Turán / Fejér). Queen S1d, 2026-10-22

Daniel Toupin / Golden Physics Project, with AI assistance from Grok. RH is OPEN. Nothing here bears on ζ's zeros.
Conventions and notation are as in `2026-10-22_noncircular_positivity_spec.md` §5 (quartet identity, f₀ = φ_L = e^{−iγ₀x} sinh(βx) on [−L, L]).

## Setup
- D is an L-function-like Dirichlet series (ζ, DH, Epstein) with an explicit formula Q(f) = Σ_ρ m_ρ ĝ(γ_ρ), and g = f * f̃.
- The target zero is ρ₀ = ½ + β + iγ₀ with β > 0.
- Normalise S(L) := e^{−2βL} · Q(f₀)/‖f₀‖².

**Expansion (PROVED by direct integration; elementary).** For a zero ρ′ = ½ + β′ + iγ′, set Δ = γ′ − γ₀. Then F(γ′ ∓ iβ′) is a combination of sinh((±β′ ± β + iΔ)L)/(±β′ ± β + iΔ). The product F(t′)·conj F(t̄′) therefore splits into a leading term and a remainder:
- Leading term: e^{2(β+β′)L}·e^{2iΔL}/(4(β+β′+iΔ)²)-type, up to the conjugate-partner term.
- Remainder: terms with exponent ≤ (β+β′+|β−β′|)L, and denominators bounded below by |β′ ± β + iΔ|.

Dividing by ‖f₀‖² = sinh(2βL)/(2β) − L ~ e^{2βL}/(4β):

  S(L) = −c₀ + Σ_{ρ′≠ρ₀} Re(c_{ρ′} w_{ρ′}^L) + E(L),  w_{ρ′} = e^{2(β′−β) + 2iΔ},  |c_{ρ′}| ≤ C_β · m_{ρ′}/(1 + Δ²),

where:
- c₀ = 1/(2β) comes from the matched pair (quartet identity, PROVED);
- the mirror pair is one of the ρ′, with Δ = −2γ₀;
- E(L) collects the subleading exponentials of every zero. Each is O(e^{−κL}/(1+Δ²)) with κ > 0, except where β′ = β. Those carry a bounded oscillating factor, already included in the Σ.

Absolute convergence: Σ_ρ m_ρ/(1+γ²) < ∞ for each D considered, by the zero-counting N(T) ≪ T log T, which holds for ζ, DH and Epstein. So Σ|c_{ρ′}| < ∞, uniformly in L ≥ 1.

## Theorem A (rightmost target; no Turán needed). Status: PROVED in sketch
The sketch is complete except for one standard check: the explicit formula must be justified for this non-smooth g. g is Lipschitz, ĝ = O(1/t²) and the zero sum converges absolutely; Weil's/Barner's conditions are standard but I have not written them out.

**Hypothesis.** β = sup_ρ (Re ρ − ½) and the sup is attained at ρ₀; any multiplicity is fine.

**Conclusion.** For every ε > 0 there is L₁(ε) such that every interval [L₁, L₁ + H] with H ≥ H(ε) contains an L with Q(f₀)/‖f₀‖² ≤ −(1 − ε)·e^{2βL}/(2β). In particular λ_min(Q_L) ≤ −(1−ε)e^{2βL}/(2β) for arbitrarily large L, i.e. c = 1/(2β) along a relatively dense set of L.

**Proof sketch.** Average S against the triangle weight τ_H on [L₁, L₁ + 2H], which has mass 1. Its Fourier transform satisfies |τ̂_H(ω)| ≤ min(1, 4/(Hω)²) (Fejér).
1. Zeros with β′ = β and Δ ≠ 0 (Δ = 0 is ρ₀ itself) contribute at most Σ |c_{ρ′}|·min(1, 1/(HΔ²)). This tends to 0 as H → ∞ by dominated convergence: the inner terms → 0 and Σ|c| < ∞. No δ-separation is needed, because only finitely many zeros lie in any box, so Δ ≠ 0 suffices.
2. Zeros with β′ < β contribute at most Σ|c_{ρ′}| e^{−2(β−β′)L₁}. This tends to 0 as L₁ → ∞, again by dominated convergence. It works even if β′ ↑ β accumulates from below.
3. E(L) → 0 uniformly in the same way.

Hence the τ_H-average of S is ≤ −c₀ + o(1), and some L in the support has S(L) ≤ −c₀(1 − ε). ∎

For DH this hypothesis is *not known*: whether sup β is attained is open (see spec §5: Saias–Weingartner, Bombieri–Ghosh). For an Epstein ζ with finitely many off-line zeros in the relevant region the hypothesis is checkable; this is the case the numerics in §5 hit (residual 0.5% at L = 4).

## Theorem B attempt (target not rightmost): the Turán step. Status: CONJECTURE (gap stated)
If some zeros have β′ > β, then |w_{ρ′}| > 1 and they dominate S(L). The matched vector then *cannot* isolate ρ₀. It can still detect *some* off-line zero; this is all Lemma 5.2 needs qualitatively (η_D ≥ 2Θ_D − 1, already PROVED via Landau). Quantitatively, the natural tool is:

- **Turán's second main theorem (PROVED, cited).** Let 1 = |z₁| ≥ |z₂| ≥ … ≥ |z_n| and b_j ∈ ℂ. For every integer M ≥ 0,
  max_{M < ν ≤ M+n} |Σ_{j≤n} b_j z_j^ν| ≥ c_{M,n} · min_{1≤j≤n} |b₁ + … + b_j|.
  - Turán's constant: c_{M,n} = 2(n/(8e(M+n)))^n (Turán, *On a new method of analysis and its applications*, Wiley 1984; Sós–Turán, Acta Math. Hung. 6 (1955) 241–255).
  - Kolesnik–Straus improvement: c_{M,n} = √n (n/(4e(M+n)))^n (*On the sum of powers of complex numbers*, Studies in Pure Math., Birkhäuser 1983, 427–442).
  - Source for the statement: Encyclopedia of Mathematics, "Turán theory", checked 2026-10-22. See also Cusick–Kolesnik, Michigan Math. J. 26 (1979) 205–211.

**What it would give (PROVED in sketch, conditional).** Apply it with ν = 2L/h on a lattice L ∈ hℤ, z_j = w_j^h, normalised so that |z₁| = 1 is the rightmost zero in a frequency window. Assume:
- (H1) only n zeros, including ρ₀, have real part ≥ ½ + β − η and |Δ| ≤ T;
- (H2) the remaining tail is ≤ ε·c_{M,n}·min|partial sums|.

Then some L ∈ [Mh, (M+n)h] has |Q(f₀)/‖f₀‖²| ≥ (c_{M,n}/2)·min|b₁+…+b_j|·e^{2β_max L}.

**Why this is not yet quantitative Lemma 5.2.** There are three gaps; each is a precise open item.
1. **Sign.** Turán bounds |Σ|, but negativity needs a lower bound for −Re Σ. One-sided Turán theorems exist (Knapowski–Turán), but their hypotheses on the b_j are not verified for our c_{ρ′}, whose phases are fixed by (β+β′+iΔ)⁻². CONJECTURE.
2. **Finiteness (H1).** For DH, zeros near σ_DH occur at all heights. Frequency localisation (CONJECTURE N, spec §8) would be needed to make n finite, and the 1/(1+Δ²) decay of |c| alone does not give (H2) with the exponentially small c_{M,n}.
3. **Partial-sum non-degeneracy.** min_j |b₁+…+b_j| can vanish by cancellation; it is uncontrolled.
