# S44 — H44a: prime-2 coupling window vs support L (GPP RH team, Grok seat)

RH OPEN. GRH OPEN. φ absent.

Setup (S13/S14 normalization): test g supported in [−h,h] (h = L, F=g*g̃ supported in [−2L,2L], so L=1.3 ↔ support 2.6).
W(c) = Pole + Arch − Σ_{n≥2, log n<2h} (2Λ(n)/√n)·F(log n), with the n=2 (k=1) weight c_true = √2·log2 = 0.980258143468547 replaced by c.
So W(c) = W_ζ − (c−c_true)T₂. Basis: Legendre·(1−u²)⁴ on [−h,h], first M functions (even/odd sectors separately). S14 exact Arb assembly (`s14_exact.py`, copied unchanged).
Per sector the generalized eigenproblem is T₂v = μ W_ζ v, with gaps δ₊ = 1/max μ and δ₋ = 1/|min μ|.

- `s44_scan.py M h1,h2,... dps prec [tower]` — Ritz gaps (NUMERICAL). `tower` also bisects the 2^k Euler-factor deformation a^k (60 steps, resolution ≈4e−19).
- `s44_cert.py M hs dps prec` — CERTIFIED outer bounds. It rounds the extreme Ritz vector x to rationals and computes r = W_ζ(x)/T₂(x) in Arb. Then T₂(x)>0 ⇒ W(c) is not PSD for c > c_true + r, and T₂(x)<0 ⇒ W(c) is not PSD for c < c_true + r.
- Outputs: `scan_M{24,40,56,72}.jsonl`, `cert_M{40,56,72}.jsonl`, combined in `s44_results.json`, and `table_ritz.md` (generated by `summarize.py`).
- Runtime: about 5 s per L at M=40, 18–48 s at M=56/72. 768–1280-bit Arb, mpmath 110–160 digits.
